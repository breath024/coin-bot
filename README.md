# 코인봇 — 코인 선물 자동매매 (정호윤 매매법)

호윤의 실거래 매매법(코인 무기한 선물, 격리 100배, 진입당 시드 5% 고정, 물타기 X,
눌림목 진입 → +20%↑ 익절 / 지지부진 시 익절 / -30% 손절)을 코드로 옮긴 프로젝트.

주식봇과 분리한 이유: 국장은 판 좁고 추적·세금 부담 대비 실익이 적음. 코인 선물로 감.

## 구조 (주식봇 설계 철학 계승: 피드·브로커만 갈아끼우면 백테스트=실거래)

```
core.py        데이터 타입 (Bar, Side, FuturesPosition, FuturesFill)
account.py     선물 계좌 — 격리 마진 + 청산
broker.py      모의 체결 — 진입/청산 + 청산·손절·익절 자동 처리
strategy.py    ★ 호윤 매매법 (눌림 진입 / 지지부진 익절) — 감 파라미터는 보정 대상
engine.py      실행 루프 (백테스트=모의=실거래 공용)
feed.py        SyntheticFeed(가짜) / CsvFeed(실데이터)
metrics.py     자산곡선 지표 + 매매통계(승률·손익비·청산횟수)
trade_log.py   매매내역 CSV
run_backtest.py  진입점
```

## 실행

```
cd 코인봇
python run_backtest.py
```

지금은 **합성데이터로 코드 검증만** 하는 단계. 성과 숫자 의미 없음.

   여기서 살아남아야 비로소 "엣지 있다".

## 100배에서 잊지 말 것

- 왕복 수수료 ≈ **증거금의 8%** (fee 0.04·100배). 익절폭 작으면 수수료가 다 먹음.
- 손절(-0.3%)·익절(+0.2%)·청산(-0.5%) 가격폭이 한 봉보다 작다 → 봉데이터 백테스트는 구조 검증용.
- 손절(-30% 증거금)이 청산(-50%)보다 먼저 닿게 설계됨 = "청산까진 잘 안 감" 반영.
  단 급락 갭은 손절을 건너뛰고 청산시킴 → `종류별`에 LIQ 찍히면 꼬리리스크 신호.
